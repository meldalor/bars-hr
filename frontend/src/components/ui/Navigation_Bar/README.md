# Навигационная панель (Navigation_Bar)

Компактная белая плавающая панель с закругленными краями для навигации по приложению.

## Описание

Панель соответствует следующим требованиям:
- Компактная белая панель с закругленными краями
- Расположена по центру экрана в верхней части
- При клике на вкладку синий овальный фон плавно перемещается между кнопками
- Текст внутри активной кнопки меняет цвет с черного на белый
- При наведении на активную кнопку синий овал слегка темнеет

## Использование

```jsx
import Navigation_Bar from "./Navigation_Bar";

function Component() {
  const [activeItem, setActiveItem] = useState("overview");

  const menuItems = [
    { id: "overview", label: "Обзор", icon: "📊" },
    { id: "vacancies", label: "Вакансии", icon: "💼", badge: "3" },
    { id: "candidates", label: "Кандидаты", icon: "👥", badge: "12" },
    { id: "meetings", label: "Встречи", icon: "📅" },
  ];

  const user = {
    name: "Александр Иванов",
    role: "HR Manager",
    avatar: null // или URL к изображению
  };

  return (
    <Navigation_Bar
      items={menuItems}
      activeItem={activeItem}
      onItemClick={setActiveItem}
      user={user}
    />
  );
}
```

## Свойства (Props)

| Prop | Тип | Обязательный | Описание | По умолчанию |
|------|-----|--------------|----------|--------------|
| `items` | `Array<Object>` | Да | Массив элементов навигации | `[]` |
| `activeItem` | `string` | Нет | ID активного элемента | `""` |
| `onItemClick` | `Function` | Нет | Callback при клике на элемент | - |
| `user` | `Object` или `null` | Нет | Информация о пользователе | `null` |

### Структура элемента навигации

```js
{
  id: "unique_id",        // уникальный идентификатор
  label: "Текст",         // текст кнопки
  icon: "📊",            // опциональная иконка (emoji или компонент)
  badge: "3"             // опциональный бейдж (число или строка)
}
```

### Структура пользователя

```js
{
  name: "Имя Фамилия",   // имя пользователя
  role: "Должность",     // должность/роль
  avatar: "url"          // опциональный URL аватара
}
```

## Особенности реализации

1. **Анимация плашки**: Синяя плашка - это единый элемент, который плавно перемещается между кнопками с помощью CSS трансформаций.
2. **Темнение при наведении**: При наведении на активную кнопку цвет плашки меняется с `#2563eb` на `#1d4ed8`.
3. **Позиционирование**: Панель позиционируется в верхней части экрана по центру через родительский контейнер.
4. **Адаптивность**: Панель автоматически подстраивается под размер содержимого.
